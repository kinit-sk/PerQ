# PerQ

The source code for the paper of "PerQ: Efficient Evaluation of Multilingual Text Platform-Adaptation Quality", accepted to the AACL-IJCNLP 2026 conference, to replicate the results.

The generated datasets with the results for the analysis is available on [Zenodo](https://zenodo.org/records/20919707).
